# REM Examples

This directory stores runnable example configs for REM, organized by source and intent.

## Layout

- `examples/palace/`: Palace-aligned examples used for behavior comparison.
- `examples/rem/`: REM-native examples, including fast demo/sanity cases.
- `examples/ansys/`: reserved for future importer alignment.
- `examples/sonnet/`: Sonnet `.sonx` converted outputs (`.json` + `.msh`).
- `examples/near_field/`: reserved domain examples.

## Sonnet Conversion Outputs

`examples/sonnet/` stores converted Sonnet19 projects generated by `rem-cli` conversion mode.

Refresh all Sonnet examples with:

```powershell
.\scripts\convert-sonnet-examples.ps1
```

Optional: include debug geometry STEP output during conversion:

```powershell
.\scripts\convert-sonnet-examples.ps1 -OutputStep
```

Optional: generate STEP and verify each expected STEP artifact exists and is non-empty:

```powershell
.\scripts\convert-sonnet-examples.ps1 -OutputStep -VerifyStep
```

Run one-command Sonnet end-to-end smoke (convert + STEP + solver):

```powershell
.\scripts\sonnet-e2e-smoke.ps1
```

This command now verifies solver artifacts too (`postpro/port-S.csv` and `postpro/s_params.s*p`).

Optional: choose a fixture and frequency:

```powershell
.\scripts\sonnet-e2e-smoke.ps1 -Fixture .\tests\fixtures\readout.sonx -FreqHz 5.0e9
```

## Fast Demo Examples (REM)

These examples are intended for web/wasm demo usage: small workload, typical setup, and quick correctness checks.

| Key (Yew) | Config | Problem Type | Mesh | Notes |
|---|---|---|---|---|
| `rem_es_fast` | `rem/es_parallel_plate_fast/es_parallel_plate_fast.json` | Electrostatic | `rem/parallel_plate/mesh/plate_2d.msh` | Minimal capacitor-style sanity check |
| `rem_ms_fast` | `rem/ms_parallel_plate_fast/ms_parallel_plate_fast.json` | Magnetostatic | `rem/parallel_plate/mesh/plate_2d.msh` | Surface current on tiny mesh |
| `rem_driven_fast` | `rem/driven_cpw_fast/driven_cpw_fast.json` | Driven | `palace/cpw/mesh/cpw_coax.msh` | Single lumped port, 2-point sweep |

| `rem_sbr_fast` | `rem/sbr_sphere_fast/sbr_sphere_fast.json` | SBR | `rem/sbr_sphere/mesh/sphere.msh` | Low ray density, 1-bounce quick check |

## Palace-Aligned Examples

Palace-aligned examples are kept under `examples/palace/` by domain:

- `adapter/`
- `antenna/`
- `coaxial/`
- `cpw/`
- `cylinder/`
- `rings/`
- `spheres/`
- `transmon/`

These are the baseline for "align first, then extend" verification workflow.

## Recommended Demo Order

For quick UI demos and regression checks, run in this order:

1. `rem_es_fast`
2. `rem_ms_fast`
3. `rem_driven_fast`
4. `rem_eigen_fast`
5. `rem_transient_fast`
6. `rem_mom_fast`
7. `rem_sbr_fast`

This order goes from cheapest/static to more expensive/time-domain.

## Notes

- Keep example files UTF-8 encoded.
- Prefer reusing validated meshes for fast demo examples.
- For new solver demos, add one fast example first, then add richer Palace-aligned cases.
